# 🏥 Insurance Data Analysis & Machine Learning

This is my second project as I continue my journey into Artificial Intelligence and Machine Learning.

## 📌 About the Project

In this project, I worked with an Insurance dataset to understand the complete data analysis and preprocessing workflow before building a Machine Learning model.

## 🔍 What I Worked On

- Data Exploration
- Exploratory Data Analysis (EDA)
- Understanding dataset structure
- Checking missing values
- Data Cleaning
- Handling categorical variables
- Encoding categorical features
- Outlier Detection
- Feature Engineering
- Feature Selection
- Data Preprocessing
- Preparing data for Machine Learning

## 🛠️ Tools & Libraries

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## 📚 Key Learnings

Through this project, I learned how important data preparation is before applying Machine Learning algorithms.

I also learned how to:
- Explore and understand a dataset
- Visualize relationships between features
- Handle categorical and numerical data
- Detect and handle outliers
- Select useful features
- Prepare clean data for ML models
